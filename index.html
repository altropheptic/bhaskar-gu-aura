How it works

  1. You act in the browser. Plain HTML, CSS and JavaScript modules: fast, accessible, no framework.
  2. A server function does the sensitive work. Vercel Functions call the AI model and privileged database operations, so no secret ever reaches your browser.
  3. Data is protected at the database. Supabase Postgres with Row Level Security on every table.
